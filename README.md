# Agenda Citas

Prototipo estático de una agenda de citas con vistas diaria, semanal y mensual.

La aplicación está publicada mediante GitHub Pages.

## Estado del prototipo

- Aplicación HTML, CSS y JavaScript sin dependencias externas.
- Las citas añadidas se conservan únicamente durante la sesión actual del navegador.
- No utiliza Firebase, base de datos ni almacenamiento persistente.
